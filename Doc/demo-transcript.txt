== 6. Redis goes down
   say: The default policy is fail-closed: with no Redis the gateway refuses traffic rather than skip the quota. Readiness goes red, liveness stays green.
$ docker compose stop redis >/dev/null 2>&1; sleep 1
$ curl -s -w ' [%{http_code}]\n' -H "Authorization: Bearer $T" 127.0.0.1:3001/api/v1/service-a/ping
{"error":{"code":"RATE_LIMITER_UNAVAILABLE","message":"Service temporarily unavailable","requestId":"e80dff0a-ab80-4037-8f42-08d306ce3e09"}} [503]
$ curl -s -o /dev/null -w 'ready=%{http_code}  ' 127.0.0.1:3001/health/ready; curl -s -o /dev/null -w 'live=%{http_code}\n' 127.0.0.1:3001/health/live
ready=503  live=200
